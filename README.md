# EasyAgenda+ | Landing page

Landing page institucional criada para o **Desafio de Projeto de CSS da DIO** (trilha Front-End). O tema é um SaaS de agendamento para barbearias e salões.

## Tecnologias

- HTML5 semântico
- CSS3 (variáveis, Grid, Flexbox, `@keyframes`, `@media`)

## Conceitos de CSS aplicados

- Seletores de tag, classe e id, e os combinadores `+` e descendente
- `margin`, `padding`, `border-radius`, `box-shadow` (inclusive `inset`)
- `text-transform`, `text-decoration`, `text-overflow` e `overflow`
- `object-fit`, `filter` e unidades relativas (`vh`, `vw`, `%`, `rem`, `ch`)
- Fontes personalizadas com `@import`
- Contadores automáticos (`counter-reset` e `counter-increment`)
- Responsividade e `prefers-reduced-motion`

## Estrutura

```
landing-page-css/
```

## Como rodar

Abra o `index.html` no navegador. Não precisa instalar nada.

## Publicação

1. Suba o projeto em um repositório público no GitHub.
2. Em **Settings > Pages**, escolha a branch `main` e a pasta `/ (root)`.
3. Cole o link gerado aqui: `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`
